# RLE String

## Problem Description
Given an encoded string in Run-Length Encoding format (or plain string to encode), compute the compressed or decoded representation as specified.

---

## Constraints
- Standard TCS CodeVita limits.
- Time Limit: 1.0 - 2.0 seconds
- Memory Limit: 256 MB

---

## Input Format
- The first line contains a string S.

---

## Output Format
- Print the run-length encoded string where consecutive identical characters are replaced with character followed by count.
