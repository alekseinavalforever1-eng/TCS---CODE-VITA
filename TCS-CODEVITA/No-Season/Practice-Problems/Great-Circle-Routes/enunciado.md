# Great Circle Routes

## Problem Description
Calculate the shortest spherical distance (great-circle route) between two geographical points on Earth given their latitudes and longitudes using the Haversine formula.

---

## Constraints
- Standard TCS CodeVita limits.
- Time Limit: 1.0 - 2.0 seconds
- Memory Limit: 256 MB

---

## Input Format
- Lat1, Lon1, Lat2, Lon2 in decimal degrees.

---

## Output Format
- Print the distance in kilometers rounded to the nearest integer.
