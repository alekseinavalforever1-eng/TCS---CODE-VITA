# Online Communities

## Problem Description
In an online social network, users form communities through friendships. Implement queries: 1 U V (connect users U and V), 2 U (query the size of the community user U belongs to), and 3 (find the maximum community size).

---

## Constraints
- Standard TCS CodeVita limits.
- Time Limit: 1.0 - 2.0 seconds
- Memory Limit: 256 MB

---

## Input Format
- N (number of users), Q (queries)
- Followed by Q query lines.

---

## Output Format
- Output results for query types 2 and 3.
