# Between Devil and Deep Sea

## Problem Description
A sailor is navigating an R x C ocean grid. The grid contains the sea (valid cells), islands, and sea monsters ('Devils'). Determine the shortest path from start to destination that maintains a safety buffer distance of at least D cells from all Devils.

---

## Constraints
- Standard TCS CodeVita limits.
- Time Limit: 1.0 - 2.0 seconds
- Memory Limit: 256 MB

---

## Input Format
- First line: R, C, D
- Next R lines: Grid where '.' is water, '#' is island, 'D' is devil, 'S' is start, 'E' is destination.

---

## Output Format
- Print the length of the shortest safe path, or -1 if unreachable.
