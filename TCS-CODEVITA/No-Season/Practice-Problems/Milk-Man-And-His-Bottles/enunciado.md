# Milk Man And His Bottles

## Problem Description
A milkman has bottles with capacities: 1, 5, 7, and 10 liters. Given target demand L liters, find the minimum number of bottles required to supply exactly L liters of milk.

---

## Constraints
- Standard TCS CodeVita limits.
- Time Limit: 1.0 - 2.0 seconds
- Memory Limit: 256 MB

---

## Input Format
- First line contains T (test cases).
- Each test case contains an integer L (liters required).

---

## Output Format
- For each test case, print the minimum number of bottles required.
