# Fill The Boxes

## Problem Description
Given a set of boxes of various capacities and a list of items of varying sizes, determine the minimum number of boxes required to pack all items such that no box exceeds its capacity. Items cannot be divided across multiple boxes.

---

## Constraints
- Standard TCS CodeVita limits.
- Time Limit: 1.0 - 2.0 seconds
- Memory Limit: 256 MB

---

## Input Format
- The first line contains an integer N representing the number of items.
- The second line contains N space-separated integers representing the sizes of the items.
- The third line contains an integer M representing the number of available boxes.
- The fourth line contains M space-separated integers representing the capacities of the boxes.

---

## Output Format
- Print the minimum number of boxes required to pack all items, or print -1 if it is impossible.
