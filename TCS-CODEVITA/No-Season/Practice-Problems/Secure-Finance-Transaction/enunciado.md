# Secure Finance Transaction

## Problem Description
A financial institution validates secure transactions using digital signatures based on modular exponentiation and checksum validation. Given transaction hash H, private key exponent D, and modulus N, compute the decrypted signature and verify if it matches the expected validation checksum.

---

## Constraints
- Standard TCS CodeVita limits.
- Time Limit: 1.0 - 2.0 seconds
- Memory Limit: 256 MB

---

## Input Format
- First line contains transaction signature S, key D, modulus N, and expected checksum C.

---

## Output Format
- Print 'VALID' if the decrypted token matches checksum, otherwise print 'INVALID'.
