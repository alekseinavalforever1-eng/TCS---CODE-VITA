# Largest Integer

## Problem Description
Given a list of non-negative integers, arrange them such that they form the largest possible number when concatenated.

---

## Constraints
- Standard TCS CodeVita limits.
- Time Limit: 1.0 - 2.0 seconds
- Memory Limit: 256 MB

---

## Input Format
- The first line contains an integer N, the number of integers.
- The second line contains N space-separated non-negative integers.

---

## Output Format
- Print the largest concatenated integer as a string.
