# Election In Disneyland

## Problem Description
In an election with multiple candidate votes, determine if any candidate has achieved a strict majority (> 50% of total votes) using Boyer-Moore Majority Vote algorithm, or find the top two candidates if a runoff is required.

---

## Constraints
- Standard TCS CodeVita limits.
- Time Limit: 1.0 - 2.0 seconds
- Memory Limit: 256 MB

---

## Input Format
- N (number of votes)
- N strings or integers representing votes for candidates.

---

## Output Format
- Print the name of the winning candidate, or 'Runoff required'.
