# Unlocker

## Problem Description
A safe lock consists of concentric rotating rings of characters or numbers. Given the current configuration of rings and the target key sequence, determine the minimum total rotations (clockwise or counter-clockwise) needed to unlock the safe.

---

## Constraints
- Standard TCS CodeVita limits.
- Time Limit: 1.0 - 2.0 seconds
- Memory Limit: 256 MB

---

## Input Format
- First line contains N, number of dials/rings.
- Second line contains the current code.
- Third line contains the secret unlock code.

---

## Output Format
- Print the minimum number of rotational steps needed.
