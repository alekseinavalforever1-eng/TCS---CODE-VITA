# Codekart

## Problem Description
Simulate an e-commerce shopping cart system with operations: ADD, REMOVE, INCR, DECR, and CHECKOUT, validating item inventory and calculating total invoice.

---

## Constraints
- Standard TCS CodeVita limits.
- Time Limit: 1.0 - 2.0 seconds
- Memory Limit: 256 MB

---

## Input Format
- Lines of operations until 'END' or 'CHECKOUT'.

---

## Output Format
- Print total bill amount or status messages.
