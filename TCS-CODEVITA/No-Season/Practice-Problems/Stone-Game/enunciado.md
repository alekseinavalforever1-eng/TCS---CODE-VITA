# Stone Game

## Problem Description
Two players play an optimal game with N piles of stones. On each turn, a player can remove 1 to K stones from any single pile. The player who cannot make a move loses. Determine who wins under optimal play using the Sprague-Grundy theorem / Nim-sum.

---

## Constraints
- Standard TCS CodeVita limits.
- Time Limit: 1.0 - 2.0 seconds
- Memory Limit: 256 MB

---

## Input Format
- First line: N (number of piles), K (max stones per move)
- Second line: N space-separated integers representing pile sizes.

---

## Output Format
- Print 'Player 1' if the first player wins, otherwise 'Player 2'.
